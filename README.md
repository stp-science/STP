# STP

Whole-school staff guidance and curriculum planning resources for St Peter’s.

## Unit Plan Guide

Interactive guidance for every planning box, with examples across subjects, presentation view and a planning checklist.

Open `unit-plan/index.html` in a browser, or enable GitHub Pages from `main` at the repository root.

## Wheel of Names

A random name picker for the classroom: type names one per line, spin the wheel (click or press Space), optionally remove winners, and keep a history of results.

Open `wheel-of-names/index.html` in a browser.
